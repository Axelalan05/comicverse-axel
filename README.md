# ComicVerse 2.0 🕷️

Migración y renovación visual de la tienda original (HTML/CSS) a Astro. Se conservaron las imágenes originales y el rojo `#BD1C1C`.

## Requisitos
- Node.js compatible con Astro 5 (Node.js 22 o superior recomendado)
- npm

## Ejecutar (Windows o Ubuntu 24.04)
```bash
npm install
npm run dev
```
Abrí http://localhost:4321

## Compilar
```bash
npm run build
```

## Qué funciona
- Navegación entre páginas, catálogo con búsqueda y filtros.
- Carrito demostrativo guardado localmente en el navegador (sin precios ni pagos).
- Diseño responsive y componentes Astro.

## Qué falta
- Login y registro reales (solo maqueta).
- Precios, stock, checkout, base de datos y pasarela de pagos.
- Revisar derechos de uso de las portadas si se publica comercialmente.
